# Justice League Accessible Design Co.

## Project Description

This project is a responsive and accessible Justice League-themed website. It uses semantic HTML, Flexbox, CSS Grid, media queries, accessible forms, alt text, and keyboard focus styles.

## Reflection Questions

### 1. What accessibility challenges did you face, and how did you address them?

One challenge was making sure the page could be used with a keyboard and that form fields were clearly labeled. I added labels, alt text, ARIA attributes, a skip link, and visible focus styles.

### 2. How did you ensure that your design was responsive and accessible to all users?

I used Flexbox, CSS Grid, and media queries so the layout could adjust for desktop, tablet, and mobile screens. I also tested the page in mobile preview to make sure text wrapped correctly and navigation stacked on smaller screens.

### 3. What tools or resources did you find most helpful during this project?

Visual Studio Code, Live Server, Chrome Inspect, GitHub, and WebAIM accessibility guidance were the most helpful tools and resources.
